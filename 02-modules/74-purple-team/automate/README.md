# Automate — Purple Team
`Run-PurpleCheck.ps1` : exécute une liste de tests Atomic et rappelle la règle à vérifier pour chacun.
`purple-plan.md` : plan de campagne (techniques, règle attendue, statut). Lab isolé.
## Usage
```powershell
.\Run-PurpleCheck.ps1 -Techniques T1558.003,T1003.001,T1070.001
```
